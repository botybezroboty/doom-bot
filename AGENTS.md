# Zasady projektu

- Bot jest zwykłym skryptem w Pythonie. Nie używaj uczenia maszynowego ani modeli AI podczas gry.
- Do gry używaj ViZDoom oraz dołączonego do niego darmowego Freedooma.
- Pracuj wyłącznie w tym repozytorium Git i jego istniejącym środowisku Python (`.venv`).
- Po każdym działającym kroku twórz commit z krótkim opisem po polsku.
- Każdą rozgrywkę zapisuj jako powtórkę w folderze `powtorki/`.
- Komunikuj się z użytkownikiem krótko i po polsku.
